## 一、spy_leaps_only_vol_target（V1 基线）

### 设计思想
用 **LEAPS 长期看涨期权**替代直接持股，以更低的资金占用获得 1-3x 杠杆暴露。通过 **7 点动量评分 + VIX 波动率目标**动态调节仓位，趋势向上时加杠杆，趋势恶化时全部退出持现金。闲置现金按 10 年期国债收益率（TNX）计算被动利息收入。

### 进场信号
**7 点动量评分**（每日计算）：

| 条件 | 分值 |
|------|------|
| Close > SMA20 | +1 |
| Close > SMA50 | +1 |
| Close > SMA200 | +1 |
| SMA20 > SMA50 | +1 |
| SMA50 > SMA200 | +1 |
| Close > 20日前收盘 | +1 |
| Close > 60日前收盘 | +1 |

**评分 → 目标暴露**：0-1→0x, 2→0.5x, 3→1x, 4→1.5x, 5→2x, 6→2.5x, 7→3x

**波动率调节**：`final_target = raw_target × min(2.0, 15/VIX)`
- VIX=15 → 1.0x（不调整）
- VIX=30 → 0.5x（减半）
- VIX=10 → 1.5x（放大）

**合约选择**（LeapsSelector）：DTE 180-400天（目标252天），Delta 0.50-0.85（目标0.70），OI≥100，bid-ask spread≤8%

### 出场/调仓信号
- **动量退出**（P10）：评分≤1 → 全部清仓
- **安全网**（P10）：DTE≤5 → 强制平仓
- **DTE Roll**（P5）：DTE≤60 → 卖旧买新（~252 DTE）
- **再平衡**：|目标-实际| > 25% 且冷却期≥5天

### 风控/仓位管理
- 仓位 = `floor(target_pct × NLV / (delta × 100 × spot))`
- 现金约束：最多用 95% 现金买入
- 杠杆上限 3.0x
- 趋势恶化时 100% 现金（无暴露）

## 二、momentum_mixed_v2（V2 改进版）

### 设计思想
在 V1 基础上增加两层风险保护：
1. **Theta Guard**（V1 改进）：提前 Roll 以减少时间价值损耗
2. **Vega Guard**（V2 新增）：VIX 异常飙升时减仓锁定利润

### 进场信号
与 V1 完全相同（7 点动量 + VIX 波动率目标 + Delta 驱动选约）

### 出场/调仓信号（V1 基础上新增）
- **Theta Guard**：Roll 阈值从 DTE≤60 提前到 **DTE≤90**。LEAPS 最后 90 天 theta 加速衰减，提前 roll 减少时间价值浪费
- **Vega Guard**（P8）：当 `VIX > 1.3 × SMA20(VIX)` 时，**减仓 50%**。长 call 有正 vega 暴露，VIX spike 时账面短期获利，但随后 vol crush 会回吐 — 锁定 spike 利润
- 其他退出规则与 V1 相同

### 风控/仓位管理
与 V1 相同，额外增加：
- Vega Guard 作为中间层，在极端波动时强制降杠杆
- 维护 `_vix_history` 做 SMA20 比较

## 三、leaps_v2_cash_sweep（V2 + 主动现金管理 + SHV 分红）

### 设计思想
在 V2 基础上，将**被动利息计算替换为实际的现金 ETF 交易 + 分红收入**。闲置现金自动买入 SHV（1-12月期国债 ETF），需要资金时自动卖出释放现金。SHV 市值视为可用流动性（与现金等价），确保 LEAPS 仓位不受影响。

回测使用 **SHV**（历史数据完整，2007 年至今）；实盘交易使用 **SGOV**（流动性更好）。

### 进场信号
与 V2 完全相同 + **Cash Sweep 入场**：
- 闲置现金 > $10,000 且可买 ≥10 股 → 自动买入 SHV
- 保留 5% NLV 作为裸现金缓冲
- **仅当策略有非现金持仓时**才买入 SHV（`require_strategy_position=True`），避免 momentum exit → 买 SHV → 卖 SHV → entry 循环

### 出场/调仓信号
与 V2 完全相同 + **Cash Sweep 出场**：
- 策略需要现金（LEAPS 入场/Roll）→ 优先卖出 SHV 释放资金
- **信号执行顺序**：EXIT → Sweep EXIT（卖 SHV）→ ENTRY（买 LEAPS）→ Sweep ENTRY（买 SHV）
- Cash Sweep 信号优先级最低（priority=-1），确保不干扰策略信号

### 风控/仓位管理
与 V2 相同，额外约束：
- **预算计算**：`budget = max_capital_pct × (cash + SHV市值)`，SHV 市值视为可用流动性
- 现金 ETF 交易豁免 DailyLimits 检查（metadata: `is_cash_equivalent`）
- 保持 5% NLV 裸现金缓冲
- 现金等价物 symbol（SGOV/SHV/BIL/SCHO）排除在 LEAPS 入场循环之外，避免被误建期权仓位

### 关键差异分析

**1. V1 → V2：风险调整收益显著提升**
- 收益 +3.54%/年，Sharpe +0.27 — Vega Guard 贡献 $2.93M（占 V2 期权收益的 27.5%），是超额收益的核心来源
- 胜率从 52.5% 跃升至 67.2% — V2 更多"小赢"（Vega Guard 提前止盈），但盈亏比下降（1.62→0.89），因为减仓也截断了大行情的尾部利润
- 代价：回撤略增（-19.5%→-21.1%），交易成本增加（$174k→$262k）

**2. V2 → V2+Sweep：真实 ETF 交易验证被动利息假设**
- 年化仅降 0.46%（29.63%→29.17%），总差距 $431k
- SHV 分红（$816k）≈ 被动利息（$809k），差距来自期权收益微小摩擦（$438k），而非现金收益
- SHV 交易净亏损仅 $5k，价格波动可忽略
- **结论**：V2 的被动利息假设是合理的，V2+Sweep 证实了真实 ETF 交易可实现

**3. V2 No Sweep：现金闲置的代价**
- 年化降 1.84%（29.63%→27.79%），终值少 $1.62M
- 与 V2+Sweep 对比：少赚 $1.19M（现金无收益 + 无复利）
- 回撤持续 746 天（最长），下行期无缓冲
- **作用**：作为纯净基线，量化现金管理（利息/分红）的真实贡献

**4. 选择建议**
- **回测研究**：用 V2（最优风险调整收益，Sharpe 1.78）
- **实盘交易**：用 V2+Sweep（真实成本结构，SHV→SGOV，当前正在 Paper 账户运行）
- **对照实验**：用 V2 No Sweep 作为纯净基线
- V1 作为历史 baseline 参考，不建议实盘使用
