## 一、spy_leaps_only_vol_target（V1 基线）

### 设计思想
用 **LEAPS 长期看涨期权**替代直接持股，以更低的资金占用获得 1-3x 杠杆暴露。通过 **7 点动量评分 + VIX 波动率目标**动态调节仓位，趋势向上时加杠杆，趋势恶化时全部退出持现金。闲置现金按 10 年期国债收益率（TNX）计算被动利息收入。

### 进场信号
**7 点动量评分**（每日计算）：

| 条件 | 分值 |
|------|------|
| Close > SMA20 | +1 |
| Close > SMA50 | +1 |
| Close > SMA200 | +1 |
| SMA20 > SMA50 | +1 |
| SMA50 > SMA200 | +1 |
| Close > 20日前收盘 | +1 |
| Close > 60日前收盘 | +1 |

**评分 → 目标暴露**：0-1→0x, 2→0.5x, 3→1x, 4→1.5x, 5→2x, 6→2.5x, 7→3x

**波动率调节**：`final_target = raw_target × min(2.0, 15/VIX)`
- VIX=15 → 1.0x（不调整）
- VIX=30 → 0.5x（减半）
- VIX=10 → 1.5x（放大）

**合约选择**（LeapsSelector）：DTE 180-400天（目标252天），Delta 0.50-0.85（目标0.70），OI≥100，bid-ask spread≤8%

### 出场/调仓信号
- **动量退出**（P10）：评分≤1 → 全部清仓
- **安全网**（P10）：DTE≤5 → 强制平仓
- **DTE Roll**（P5）：DTE≤60 → 卖旧买新（~252 DTE）
- **再平衡**：|目标-实际| > 25% 且冷却期≥5天

### 风控/仓位管理
- 仓位 = `floor(target_pct × NLV / (delta × 100 × spot))`
- 现金约束：最多用 95% 现金买入
- 杠杆上限 3.0x
- 趋势恶化时 100% 现金（无暴露）

在 V1 基础上增加两层风险保护：
1. **Theta Guard**（V1 改进）：提前 Roll 以减少时间价值损耗
2. **Vega Guard**（V2 新增）：VIX 异常飙升时减仓锁定利润

### 进场信号
与 V1 完全相同（7 点动量 + VIX 波动率目标 + Delta 驱动选约）

## 三、leaps_v2_cash_sweep（V2 + 主动现金管理 + SHV 分红）

### 设计思想
在 V2 基础上，将**被动利息计算替换为实际的现金 ETF 交易 + 分红收入**。闲置现金自动买入 SHV（1-12月期国债 ETF），需要资金时自动卖出释放现金。SHV 市值视为可用流动性（与现金等价），确保 LEAPS 仓位不受影响。

回测使用 **SHV**（历史数据完整，2007 年至今）；实盘交易使用 **SGOV**（流动性更好）。

### 进场信号
与 V2 完全相同 + **Cash Sweep 入场**：
- 闲置现金 > $10,000 且可买 ≥10 股 → 自动买入 SHV
- 保留 5% NLV 作为裸现金缓冲
- **仅当策略有非现金持仓时**才买入 SHV（`require_strategy_position=True`），避免 momentum exit → 买 SHV → 卖 SHV → entry 循环

### 出场/调仓信号
与 V2 完全相同 + **Cash Sweep 出场**：
- 策略需要现金（LEAPS 入场/Roll）→ 优先卖出 SHV 释放资金
- **信号执行顺序**：EXIT → Sweep EXIT（卖 SHV）→ ENTRY（买 LEAPS）→ Sweep ENTRY（买 SHV）
- Cash Sweep 信号优先级最低（priority=-1），确保不干扰策略信号

### 风控/仓位管理
与 V2 相同，额外约束：
- **预算计算**：`budget = max_capital_pct × (cash + SHV市值)`，SHV 市值视为可用流动性
- 现金 ETF 交易豁免 DailyLimits 检查（metadata: `is_cash_equivalent`）
- 保持 5% NLV 裸现金缓冲
- 现金等价物 symbol（SGOV/SHV/BIL/SCHO）排除在 LEAPS 入场循环之外，避免被误建期权仓位

## 四、leaps_short_put_v3（V3 — LEAPS + Bull Put Spread Overlay）

### 设计思想
用 **Bull Put Spread 卖权策略**替代 V2 的被动利息收入（TNX），利用 ~75-80% 闲置现金的保证金卖出 OTM put spread 赚取权利金。与主策略使用同一标的（SPY），形成 synthetic covered call 效果（long LEAPS call + short put）。主策略 MomentumMixedV2 完全独立运行，overlay 不干扰其信号。

### 进场信号
**LEAPS 主策略**：与 V2 完全相同（7 点动量 + VIX 波动率目标 + Theta/Vega Guard）

**Overlay 入场门控**（全部满足才开仓）：
- G1: momentum_score > 0（主策略看多）
- G2: 有 LEAPS 主仓位
- G3: VIX < 35
- G4: 未在 VIX spike 冷却期内
- G5: 当前 spread 数 < max_spreads（10）
- G6: 可用保证金 > 0

**Overlay 合约选择**：
- Short put: delta=0.20（范围 0.15-0.25），DTE 30-45 天
- Long put: short strike - $5（spread width），同到期日
- 决策频率: 每 3 个交易日检查一次

**VIX 仓位缩放**：VIX < 25 → 全仓 | VIX ∈ [25,30) → 半仓 | VIX ∈ [30,35) → 1/4 仓 | VIX ≥ 35 → 不开新仓

### 出场/调仓信号
**LEAPS 部分**：与 V2 完全相同（Theta Guard DTE≤90 roll, Vega Guard VIX spike 减仓, Momentum Exit）

**Overlay 退出**（按优先级）：
- P9: VIX 单日涨幅 > 20% → 全部平仓 + 5 天冷却
- P8: Momentum = 0 → 全部平仓
- P5: 止盈 — 收益达最大利润的 50%
- P5: DTE ≤ 7 天 → 平仓避免 gamma 风险

**信号合并优先级**：LEAPS EXIT → Overlay EXIT → LEAPS ENTRY → Overlay ENTRY

### 风控/仓位管理
- LEAPS 部分：与 V2 完全相同
- Overlay 保证金：`(cash + cash_equiv - 10% NLV) × 50%`
- 单 spread 保证金 = `spread_width × 100 - net_credit × 100`（定义风险）
- 最多 10 组并发 spread
- 被动利息关闭（`cash_interest_enabled=False`）

### 关键结论

V3 的 bull put spread overlay **失败**，原因：
1. **替代而非叠加**：V3 关闭了被动利息（`cash_interest_enabled=False`），用 overlay 完全替代，但 overlay 净贡献为负
2. **Spread 权利金太低**：$5 宽度的 OTM spread，net credit 仅 $0.50-$1.50/组，年化收益率远低于 4% 国债利率
3. **高频交易摩擦**：628 笔 PUT 开仓带来额外佣金/滑点
4. **行权风险**：8 次 ITM 行权锁定大量现金，间接影响主策略
5. **复利损失**：V2 的被动利息每日复利，10 年效应巨大；overlay 收入不稳定且无法复利

## 五、leaps_vixterm（VIX 期限结构择时 + Vega Guard + SHV Sweep）

> 回测区间: 2015-01-01 ~ 2025-12-31 | 标的: SPY | 初始资金: $1,000,000

### 设计思想
用 **VIX/VIX3M 期限结构**替代 V2 的 Vol Target（`min(2, 15/VIX)`）作为杠杆缩放机制。VIX/VIX3M 比值反映短期 vs 中期恐慌程度：正常市场 VIX < VIX3M（contango），恐慌时 VIX > VIX3M（backwardation）。同时**保留 Vega Guard**（VIX 脉冲减仓），两者覆盖不同风险维度：
- **VIXTerm**：结构性恐慌/危机检测（2020 COVID、2018Q4、2025 Tariff）
- **Vega Guard**：VIX 脉冲式飙升的快速响应（局部事件、闪崩）

闲置现金通过 **SHV Cash Sweep** 管理（与 V2+Sweep 相同）。

### 进场信号
**7 点动量评分**与 V1/V2 完全相同。

**VIX 期限结构缩放**（替代 Vol Target）：

| VIX/VIX3M 比值 | 动作 | 触发频率 |
|----------------|------|---------|
| ≥ 1.15（严重 backwardation） | target = 0（全部退出） | ~1.6% 交易日 |
| ∈ [1.05, 1.15)（温和 backwardation） | cap 1.0x | ~0.5% 交易日 |
| ∈ [1.00, 1.05)（近平坦） | cap 2.0x | ~2.3% 交易日 |
| < 1.00（正常 contango） | pass-through | ~78.1% 交易日 |
